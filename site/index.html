API de chamados de suporte

Estrutura inicial de uma API desenvolvida com Python e Flask.

Rota inicial

GET / responde com status HTTP 200 e conteúdo JSON:

{
  "mensagem": "API de chamados em funcionamento"
}

Esta página do GitHub Pages é documentação estática. O Pages não executa o servidor Flask. Para acessar a API, inicie-a localmente ou em um serviço que suporte aplicações Python.

Executar a API

  1. Instale as dependências com uv sync --locked.
  2. Inicie com uv run flask --app app run --host=0.0.0.0 --port=5000.
  3. Acesse http://localhost:5000/.

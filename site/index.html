API de chamados de suporte

Exemplo da resposta JSON da rota inicial da API desenvolvida com Python e Flask.

Endpoint JSON no GitHub Pages

Método: GET

URL: ./api.json

O arquivo retorna status HTTP 200, com Content-Type: application/json e este corpo:

{
  "mensagem": "API de chamados em funcionamento"
}

Este endpoint é um arquivo JSON estático publicado pelo GitHub Pages para demonstrar a resposta. A rota Flask real está em app.py; o Pages não executa o servidor Python.

Executar a API Flask

  1. Instale as dependências com uv sync --locked.
  2. Inicie com uv run flask --app app run --host=0.0.0.0 --port=5000.
  3. Acesse http://localhost:5000/ para chamar a rota Flask.
